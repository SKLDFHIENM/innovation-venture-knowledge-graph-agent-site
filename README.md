# 创新创业课程知识图谱智能体

> Knowledge Graph Agent for Innovation & Entrepreneurship Course

本仓库为「创新创业课程知识图谱智能体」项目源码，面向高校创新创业课程，提供课程知识图谱的可视化展示、讲解、测评与演示等模块。

## 功能模块

- **知识图谱主界面**：`index.html`、`knowledge_graph.html`、`graph.html`、`map.html`
- **测评与讲解**：`exam.html`、`glossary.html`、`help.html`、`chat.html`
- **演示文稿（HTML/Deck）**：`decks/`、`presentation.html`
- **前端逻辑与样式**：`js/`、`css/`、`fonts/`、`webfonts/`
- **图谱数据**：`data/`
- **构建与数据处理脚本**：`scripts/`
- **自动化测试**：`tests/`

## 本地运行

无需构建，直接用浏览器打开 `index.html` 即可使用。
