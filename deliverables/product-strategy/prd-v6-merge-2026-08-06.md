## 1. 深度对比评估

### 1.1 系统架构设计对比
- **V6.0 CODEX 分支**：采用了极其彻底的模块解耦思想。引入 `.agents/` 独立的 Agent 描述与协议架构，解耦了前端 UI 与后端智能体调度机制；将知识图谱节点、边、关系权重从单纯的图形渲染中剥离出来，形成了独立的 `graph_core.js` 与数据加工流。
- **主分支**：侧重于全站 UI 布局、部署构建脚本（如 `create_landing.js`, `generate_index.js`, `make_landing.py`）以及可视化表现层的稳定表现。但在高并发多 Agent 交互与协同推演上，原有的上下文缓存与容错机制略显不足。

### 1.2 核心业务逻辑与 Agent 协同机制对比
- **V6.0 CODEX 分支**：内置了四角色（需求分析师、用户研究员、竞品分析师、路线图规划师）研讨与协同机制。在 `ai_agent.js` 中实现了基于 EventBus 的状态广播与协同调度，支持异步任务状态流转与失败回退机制。
- **主分支**：单 Agent 对话能力完善，但在多角色协同研讨、角色动态切换与会话上下文状态隔离方面依赖全局变量，存在一定隐患。

## 2. 100+ 条分类优化与重构建议

### 一、系统架构与模块解耦（1-18条）
1. **统一 EventBus 抽象**：抽取全局 `EventBus` 模块，替换基于 `window.dispatchEvent` 的松散事件触发。
2. **状态管理集中化**：引入轻量级状态机 `Store`，统一管理 Graph 节点状态与 Agent 会话状态。
3. **隔离数据层与视图层**：将 Vis.js / D3.js 渲染逻辑与知识图谱实体逻辑彻底分离。
4. **Agent 引擎组件化**：将 `ai_agent.js` 重构成可插拔的 Agent Class 继承体系。
5. **动态模块加载机制**：使用 ES Module 的 `import()` 实现次要视图（如 exam/activities）的按需加载。
6. **配置文件中心化**：收拢 API 路径、模型配置、超时阈值至 `js/config/app_config.js`。
7. **建立依赖注入机制**：避免模块直接依赖全局 `window` 对象，提高单元测试可行性。
8. **组件生命周期规范化**：为可视化组件统一定义 `init()`, `update()`, `destroy()` 标准接口。
9. **服务层抽象 (Service Layer)**：抽取 `GraphDataService` 与 `AgentMessageService` 统一管理网络请求。
10. **分离业务数据与UI动画状态**：确保数据变更不直接依赖动画帧，提升渲染帧率。
11. **主分支部署工具链标准整合**：将 `make_landing.py` 与 `create_landing.js` 统一纳入构建脚本规范。
12. **封装本地存储持久化层**：统一 `localStorage` 与 `indexedDB` 的读写隔离，防范存储越界。
13. **Worker 线程分离重算法**：将知识图谱大节点路径计算移动至 Web Worker 运行。
14. **CSS/JS 资源统一注册**：建立统一的脚本加载管道，防止资源重复引入。
15. **支持多沙箱隔离执行**：避免不同页面共享全局 Agent 上下文带来的污染。
16. **组件沙箱降级机制**：当 Vis.js 渲染失败时自动回退为 SVG 静态树图。
17. **模块版本控制规范**：在 `js/modules/version.js` 中记录关键子系统版本号。
18. **前端路由轻量化重构**：统一 hash 与 history 路由的管理逻辑，提升多页面体验。

### 二、知识图谱构建与数据建模（19-35条）
19. **规范图谱实体 Schema**：定义严格的 Node/Edge TypeScript 风格接口或 JSDoc 类型声明。
20. **建立概念层与实例层双层图谱**：区分课程大纲抽象概念与具体案例/项目数据。
21. **图数据缓存更新策略**：基于 ETag/MD5 的本地缓存校验机制，减少静态 JSON 重复拉取。
22. **节点关系权重归一化**：规范化关联度得分（0.0 ~ 1.0），提升路径寻优精准度。
23. **模糊搜索与拼音索引支持**：在客户端对图谱节点建立 FlexSearch/Fuse.js 轻量索引。
24. **多维标签系统集成**：支持按能力维度（如商业模式、市场分析、技术壁垒）筛选节点。
25. **节点同义词合并词表**：构建近义概念映射字典，消除冗余重复节点。
26. **图谱版本回滚与快照机制**：保存用户探索路径与节点选择的历史快照。
27. **层次化节点展开算法**：避免一次性渲染数千节点导致浏览器卡顿。
28. **子图导出与导入功能**：支持将部分研讨子图导出为 JSON/PNG。
29. **实体关联断言校验器**：数据载入前自动检查孤立节点与无效边。
30. **案例与知识点双向绑定机制**：点击商业计划书案例自动高亮关联的理论知识点。
31. **图谱视口智能聚焦计算**：根据搜索命中节点自动计算适宜的 Zoom & Center 参数。
32. **动态力导向参数自适应**：节点数量过多时自动降低斥力强度，提升渲染性能。
33. **节点图谱语义距离算法**：基于最短路径算法计算任意两个创新创业概念的耦合度。
34. **知识图谱热力图集成**：记录并高亮学生访问与测试错题高频知识点。
35. **实体元数据扩充接口**：为每个节点预留标准扩展字段（如推荐文献、视频链接）。
